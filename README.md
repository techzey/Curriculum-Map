# 🎓 Mechanical Engineering Curriculum Tracker

An interactive, single-page web application designed for 1st-year Mechanical Engineering students to track their academic progress, prerequisites, and unit completions.

---

### 🚀 [Click Here to Access the Live Site](https://techzey.github.io/Curriculum-Map/)

---

## ✨ Features

* **Interactive Course Tracker:** Click any course card to cycle through statuses:
  * ⚪ **Not Taken**
  * 🟠 **In Progress**
  * 🟢 **Passed**
* **Live Progress Metrics:** Real-time calculation of total units completed, remaining units, and completion percentage.
* **Prerequisite Checks:** Displays prerequisites and co-requisites directly on every course card.
* **Local Progress Storage:** Course states automatically save to the browser's local storage—no account creation or login required.
* **Filtering Options:** Filter courses quickly by status (*All*, *Passed*, *In Progress*, or *Not Taken*).

---

## 🛠️ How to Use

1. Open the [Live Tracker](https://techzey.github.io/Curriculum-Map/).
2. Click on a course box to update your current status for that subject.
3. Use the filter buttons at the top to view specific subject groups.
4. If you need to start over, click the **Reset All** button at the top right.

---

## 📌 Technology Stack

* **HTML5**
* **CSS3** (Flexbox & CSS Grid)
